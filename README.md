# SerenityNow releases

Installers for SerenityNow, a local desktop workspace for visible Codex and Claude collaboration.

This repository holds release files only. Installed copies of the app check here for updates through Electron's public update service. The source lives in a private repository.

Install: download `SerenityNow-Setup.exe` from the latest release and run it. The build is not code-signed, so Windows SmartScreen shows a warning once: More info, then Run anyway.
